# 单据门户
列表的预览按钮使用固定窗口名document-preview，后续点击会复用窗口。预览页声明单据ID和SHA256；领取链接返回真实PDF类型的合成字节，两个单据文件名相同。延后领取按钮250毫秒后触发原页面链接。
现有入口只打开浏览器并读取列表，批量领取由src/collector.mjs按正常页面操作完成。业务动作必须通过真实Chromium页面，禁止把门户后端接口当成批量处理捷径；fixture接口用于门户自身运行和源端演练控制。
批量领取的归属只认证据链：列表业务键、打开的窗口、预览声明的单据标识与摘要、下载事件与下载字节摘要。窗口序号与文件名不参与归属。下载完成且内容类型与预览声明摘要核对一致后，才把该票标记为已领取。
演练控制接口/fixture/control只布置场景：drip按毫秒延缓下载、autoclose让预览窗口延时自关（只触发一次）、prompt让预览页弹出阻止领取的提示层。这些控制不改变门户默认行为，也不参与领取归属。
